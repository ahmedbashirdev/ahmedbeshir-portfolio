Your request, tracked live.

A request is a promise. This screen keeps that promise visible — who is on it, when it is expected, and a live thread the guest, the staff member and hotel management all share.

  • Straight to the specialist

    The guest requests a service directly from the relevant specialist — no front-desk relay, no message lost in translation along the way.

  • Time-tracked against an SLA

    Every request runs against a service-level target, with a clear expected-by time the guest can see — here, 15:30.

  • Comment while it's live

    The guest can add a comment on the request while it is still in progress — adding context, urgency, or a simple thank you.

  • Management sees it too

    Those comments are visible to hotel management. A complaint never quietly disappears — it is on the record from the first minute.

  • Accountability, built in

    Because guest, staff and management all watch the same request live, accountability is built in — and being watched is what drives speed and quality.

Where this sits

This screen completes the services flow — catalog and offers, then service detail, then the request composer, and finally request tracking. It follows the request lifecycle: Submitted → Assigned → In progress → Completed.
